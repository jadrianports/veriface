# Architecture Decision Records

An ADR captures one significant, load-bearing architectural decision: the context that forced it, the options actually weighed, and the outcome. Records are numbered and never edited after acceptance — a changed decision is a new record that supersedes the old one, and the superseded record keeps its original text.
